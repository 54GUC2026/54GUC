## Free activation and optional donations

The application's existing activation and code generator are unchanged.
Monitoring does not require activation; supported controls still use a valid
code for the connected modem. Licences are free and donations are optional.
No payment is required to request a code.

The source includes the existing generation and checking logic. Anyone with
that source can generate codes accepted by the unchanged application. This is
an intentionally accepted part of the free open-source release; activation is
not protection against someone generating a code. No new signed-code format,
replacement-code migration or private signing-key setup is part of this release.

The GPL software licence and the app's activation check are different things.
Activation does not limit the rights granted by GPL-3.0-only or promise that
an unsupported router command will work.
