# Where we'd like to take 54GUC

We want mobile-broadband routers to be easier to understand, compare and improve. More people testing their own hardware means more useful profiles, clearer readings and a better app for everyone.

## First priority: more routers in real use

The most valuable contribution today is trying the current app on an unsupported or partly explored router. Which fields are available? What does a different firmware return? What would make the app more useful on that device?

A report can start with a model name and a question. From there, we can build up examples, a draft profile and feedback from other owners. Every newly understood field moves things forward; monitoring-only support is a worthwhile result.

## Interesting work to explore

- **New profiles:** extend coverage to more models, firmware versions and provider variants.
- **More useful readings:** discover native 5G, carrier, traffic, temperature and device-status information.
- **Flexible input handling:** understand equivalent response shapes, field names and explicit units across firmware versions.
- **Clearer reports:** help people understand their connection without needing to decode a technical log.
- **Better experiments:** create synthetic replies, replay examples and simulator scenarios that make development easier without owning every router.
- **A friendlier app:** improve setup, explanations, accessibility and the experience when a reading is temporarily unavailable.
- **Better advice:** investigate how connection history and the advisory engine can become more useful in everyday use.

These are starting points, not a fixed assignment list. Pick something that interests you, or bring a different idea. Forks and independent experiments are welcome too.

## A small contribution can go a long way

One owner might discover a new field, another might add its mapping, and someone else might test a second firmware. A useful profile can grow through several small contributions. Questions, incomplete experiments and draft pull requests all help that process.
