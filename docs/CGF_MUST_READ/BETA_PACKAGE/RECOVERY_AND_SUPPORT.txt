54GUC R25.7 — RECOVERY AND SUPPORT
==================================

Release: 54GUC_R25.7

Prepared for: 54GUC R25.7

Use the matching published release record for download availability and
completed checks. Follow the instructions for the actual app you have.
Existing activation and code formats are unchanged.

If something goes wrong, first read the message on the Device page. It
normally says whether 54GUC cannot reach the router, can reach it but
cannot log in, or is connected while the router has no mobile service.

IF 54GUC CANNOT CONNECT TO THE DEVICE

1. Check that the computer is on the router's Wi-Fi or Ethernet.
2. Open the router's local address in a browser. If that also fails,
   restore the local connection before retrying 54GUC.
3. Check the exact model, address, user name and router login password.
   The router password is not remembered between app starts.
4. Press CONNECT and read the result. If a model or firmware is not covered,
   the profile workshop can help you investigate a new draft.

IF DEVICE IS CONNECTED BUT MOBILE NETWORK IS NOT

Leave 54GUC open. Device and mobile network are separate connections;
monitoring can continue while the router seeks service. Read the progress
and the last router result. Check the SIM, provider service and router's
own status. If you deliberately chose roaming, a network or an APN,
confirm that the current settings match the service instructions.

To change an editable choice, press DISCONNECT, correct the named field
and press CONNECT again. A bad or incomplete SIM/network entry should be
explained and should not silently change the router. With no deliberate
change, 54GUC follows the router's existing mobile settings; it does not
force automatic connection to other saved networks.

On MikroTik, make SIM, roaming, network and APN changes in RouterOS.
54GUC shows what the router reports but cannot make those changes there.
On a G5TC B17, the router may refuse or later change an operator/APN
request. A sent request is not proof of success; check the final serving
network and the router's own settings.

ACTIVATION

Existing valid activation codes continue to work. START_HERE.txt explains
the activation procedure. If a code is refused, check that it matches the
connected modem and that both Nonce and Key were copied completely. The app
version and displayed message are useful details for a support question.

IF A BUTTON OR READING IS MISSING

Move the pointer over a disabled control to read why it is unavailable.
UNSUP. means the exact router profile does not provide it. N/A, Unknown
or --- means no confirmed reading yet. Wait for another reading, then
check whether the router supplies that information. A missing reading
and a measured zero mean different things.

IF A MANUAL OR BRAIN CHANGE SEEMS WRONG

Read Manual Action Result and Recent Events. Check the router's current
band, cell or Wi-Fi state. A request may be refused, time out or be
changed again by the router. Its final result helps you choose the next step.
Set Brain OFF if you want to watch without new automatic changes; an
already-started action may finish first.

4G AND 5G RECOVERY

Startup keeps the mode and bands it reads from the router. If you selected
4G-only, 54GUC does not enable 5G just because the app has started.

There are two paths. If mode control is supported and the router confirms
its current settings, confirmed poor active 5G that harms service can cause
a temporary switch to 4G-only. The saved 5G choice is retried after 30, 60
and 90 minutes. A good trial needs 120 seconds of good fresh readings.
If mode control is unavailable, 54GUC keeps monitoring and ordinary LTE
recovery; use the router WebUI for mode changes.

4G/Internet recovery always comes first, including on a 5G router. A due
5G retry waits until LTE service is stable and recovery holds have cleared.
The LTE band pool recovered during that process is retained.

Read Dashboard Recent Events for the current phase and retry time. A
message asking you to review settings means automatic retries are paused;
no repeated radio command is being sent. Manual changes, changed device
or SIM, or an uncertain router result can stop the previous plan.

Some routers permit only one login. Close 54GUC normally before logging
into their WebUI, then restart 54GUC after finishing your changes.

IF THE APP NEEDS TO STOP OR RESTART

Use SHUTDOWN and wait until it closes. The 54GUC_Control.cmd stop command
is another supported way to stop it. Waiting for shutdown lets the app
finish its saved records before a new session.

Valid history for this router is kept separately from the app folder.
If history is missing or damaged, basic monitoring can start with new
learning. Keeping each router's own History makes comparisons clearer. Saved
settings live under %LOCALAPPDATA%\54GUC; keep them if you want your
router and APN choices on the next start. Use Previous Version Import
only when the app offers that specific transfer.

SUPPORT BUNDLE

The ZIP covers the selected run, up to its latest 24 hours. Private data is
removed at the final export stage. The original saved history is unchanged.

Press SUPPORT BUNDLE and wait for the completed message. The newest ZIP
is in support_bundles. If the app cannot open, use the
54GUC_Control.cmd bundle command from its extracted folder.

Review the ZIP before sending it privately to your beta contact. Include
the app version, exact router model and firmware, time of the problem,
what you did and the message you saw. Practical sharing tips are linked
below. Export may take time
when this router has many saved readings; progress appears in the app.

LOG CHECKER 2.0

Run Log Checker 2.0 against the support ZIP, or place its EXE beside 54GUC.exe
and close 54GUC before checking that folder. Keep the supplied notice files
with the checker. Its report explains what was found and what to check next;
raw details remain available. Use only that router's matching History.
A live-export bundle can legitimately report that shutdown was not yet saved.
Privacy-masked input cannot be used to confirm the original private value.

Read USER_GUIDE.txt beside this file for the six pages. The website's
manual and pictures may describe an older build. Use the Log Checker supplied
or recommended for the actual release; an older copy may not understand its
new saved fields.
