54GUC WINDOWS - START HERE
================================

Release: 54GUC_R25.7

Prepared for: 54GUC R25.7

Use the matching published release record for download availability and
completed checks. Follow the instructions for the actual app you have.
Existing activation and code formats are unchanged.

54GUC shows what a supported 4G/5G router is doing. It can show signal,
Internet status, data use and past results. Some supported routers also
allow manual or automatic changes. Start by watching, not changing.

FIRST CONNECTION

1. Extract the complete ZIP into a new folder on your Windows computer.
   Do not start 54GUC from inside the ZIP.
2. Connect your computer to the router by Wi-Fi or Ethernet.
3. Open 54GUC.exe. Select the router's make and exact model.
4. Enter the router's local address, user name and login password.
5. Choose Observe only. Press CONNECT once and wait.
6. Look for Device: Connected. Mobile network is a separate status.
   If the router has no mobile service, 54GUC can still stay connected to it.

The app remembers your router, address, user name and SIM/network/APN choices.
Check them next time. It does not save the router login password, so enter
that again each time you start the app.

You do not need a license to connect and monitor. Changing router settings
needs Live mode and a valid license for that modem. A radio change can stop
Internet service briefly; make changes only when you can reach the router
locally.

ACTIVATION

Activation stays the same in this candidate. Connect the intended modem and
wait until its serial or IMEI is available. Choose LICENSE, paste the
NONCE-KEY text or the complete Nonce/Key block made for that modem, then choose
Validate & Activate. Wait for Licensed before using supported controls.

Licences are free. BUY LICENSE keeps its existing button name and explains
how to request one; it does not require a payment. Donations are optional.
Publishing the source does not require a new code or a special activation
upgrade. Keep an existing valid code for the same modem, settings and History.
Do not delete them or reset the router to resolve an activation problem.

The public source retains the existing code generator and checking logic, so
people with that source can also generate valid codes. This is an accepted
part of the free open-source release. Activation still does not add controls
that the exact router profile cannot support.

SIM AND NETWORK

For a normal first connection, leave SIM & Network as it is. 54GUC reads
the active SIM and the router's current choices. To change an editable
network or APN setting later, press DISCONNECT, edit the fields, then CONNECT.
An incomplete or conflicting choice is explained; it does not block login
to the router or silently change its mobile settings.

MikroTik SIM, network and APN fields are read-only in 54GUC. Use RouterOS
to change them. A G5TC or another router may have different supported
controls; the app will show when a requested action is unavailable.

IF SOMETHING GOES WRONG

- Cannot connect to the router: check the Wi-Fi/Ethernet link, router
  address, exact model, user name and password. Read the message in 54GUC.
- Device connected but Mobile network disconnected: leave 54GUC open and
  read its progress. The router may still be trying to get service.
- A value is blank or says N/A: wait for another reading. Missing is not zero.
- A router change fails: read the final result before trying again.
- To stop, use SHUTDOWN and wait for the app to close. Do not force-close
  or start a second copy while it is stopping.

For support, press SUPPORT BUNDLE. Review the newest ZIP in support_bundles
and send it privately to project support. Do not send your router password,
license file or SMS secrets.
