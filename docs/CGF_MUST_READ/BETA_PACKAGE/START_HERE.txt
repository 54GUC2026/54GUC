54GUC WINDOWS - START HERE
==========================

Release: 54GUC_R25.7

Welcome! 54GUC brings your router's signal, traffic, connection history and
available controls together in one place. Start by exploring the readings;
you can try more of the app as you become familiar with your setup.

FIRST CONNECTION

1. Download the Windows portable ZIP and extract it into a fresh folder.
2. Connect your computer to the router by Wi-Fi or Ethernet.
3. Open 54GUC.exe and select the router's make, model and firmware profile.
4. Enter its local address, user name and login password.
5. Choose Observe only, press CONNECT and wait for the result.
6. Look for Device: Connected. Mobile network is a separate status, so
   the app can stay connected to the router while it seeks mobile service.

The app remembers your router and several connection choices. Enter the
router login password again when starting a new session.

TRY THE FEATURES

Monitoring is available without activation. For supported controls, use
Live mode and activate the connected modem: choose LICENSE, paste its
NONCE-KEY text or complete Nonce/Key block, then Validate & Activate.
Wait for Licensed. Existing valid codes continue to work.

Activation is free. The BUY LICENSE button explains how to request a code;
donations are optional. The existing generator is also in the public source.

For an ordinary first connection, leave SIM & Network at its current
settings. To edit an available network or APN choice later, DISCONNECT,
edit the field and CONNECT again. Available choices depend on the profile.
