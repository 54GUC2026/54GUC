54GUC R25.7 — HARDWARE AND LIMITS
=================================

Release: 54GUC_R25.7

Prepared for: 54GUC R25.7

Use the matching published release record for download availability and
completed checks. Follow the instructions for the actual app you have.
Existing activation and code formats are unchanged.

Choose the exact model and firmware. A similar-looking router, a different
firmware version or a provider-branded variant is not automatically covered.
"Manual Control Verified" and "Detected and Monitored" are physical-router
evidence levels. "Simulator only" means the application flow was checked
against a software model; it does not certify a physical router.

This short list records the evidence levels below; it is not the whole
profile catalogue. An entry in the model selector does not mean every feature
was tried on physical hardware. The Site Report's What this router supports
section helps explain the selected profile's available fields and controls.
It does not turn missing readings into values or certify an untested router.

ACTIVATION DOES NOT ADD ROUTER FEATURES

A valid activation code permits only controls already supported for that
modem. It cannot add a missing router command or upgrade a simulator result
into physical proof. Activation is unchanged: use the existing modem-bound
NONCE-KEY or complete Nonce/Key block described in START_HERE.txt. Publishing
the source does not require replacing an existing valid code.

LIMITS THAT APPLY ACROSS PROFILES

- Control availability is determined by the exact profile and current
  router response, not just the model name.
- A CA Pool lists allowed LTE bands. It is neither all hardware-capable
  bands nor proof that every band is active.
- 5G NSA data may be displayed. Mode switching and NR band control are
  separate capabilities. A profile can support temporary 4G-only recovery
  and saved 5G-mode restoration without permitting manual NR band writes.
  Manual NR requires a qualified exact profile, such as NX520 Build250902.
  Standalone 5G optimization is not supported. The physical evidence levels
  listed above remain specific to those profiles and operations.
- Cell lock accepts PCI 0..503 with a valid positive EARFCN only when the
  exact firmware supports that control. NX520 Build250902 does not.
- Congestion, capacity and quality are app estimates, not official
  provider values or guaranteed speeds.
- UNSUP. means this device cannot provide that information. ---- means a
  supported reading is currently missing or unconfirmed. A 5G-capable device
  temporarily using LTE keeps its NR fields supported and shows ----. An
  unsupported NR section is labelled once rather than repeating each value.
- Mobile-network and APN changes may briefly interrupt service. Confirm
  the final router state rather than assuming a sent request was accepted.
