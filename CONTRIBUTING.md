# Help build 54GUC

Have a 4G or 5G router, an idea, or something you would like to improve? You're welcome here. You can contribute a quick observation, an experiment, a draft profile, a bug fix, or clearer documentation. You don't need a finished solution to start a conversation.

Our biggest need right now is **trying the current software on more routers and firmware versions, then turning what we learn into useful profiles**. Hardware owners can make a big difference, with or without programming experience.

## Help test more routers

Try [the current Windows release](https://github.com/54GUC2026/54GUC-Releases/releases/tag/R25.7) and tell us about your router. A helpful first report can be just:

- The model, hardware revision and firmware version you know.
- The app version and profile you tried, if you've tried one.
- What worked, what looked different, and what you'd like to explore next.

Missing support is a useful finding too. If your model isn't listed, open a [router-test report](https://github.com/54GUC2026/54GUC/issues/new?template=router-test.yml). A description is enough to get started; screenshots, programming knowledge and control tests are optional.

For a first connection, **Observe only** is a useful way to explore the readings. The [hardware guide](docs/CGF_MUST_READ/BETA_PACKAGE/SUPPORTED_HARDWARE_AND_LIMITATIONS.txt) shows our current starting points. A new firmware or an unfamiliar format is an opportunity to improve them.

## Explore a profile

Profiles connect a router's native information to the app. You might uncover a new reading, recognize another response format, improve a unit conversion, or help bring a new model into the catalogue.

Start with [the profile workshop](docs/ROUTER_PROFILES.md). It walks through choosing a related profile, making a separate draft and testing an example. Monitoring-only support is already a valuable contribution. An early draft or a question in a [profile proposal](https://github.com/54GUC2026/54GUC/issues/new?template=profile-proposal.yml) is welcome.

## Other ways to help

- Make the Site Report or a screen easier to understand.
- Investigate a bug or add a test for an unusual reply.
- Improve setup instructions, examples, translations or accessibility.
- Research a router's API and share useful references.
- Try someone else's draft and report what happens on your hardware.

The [project goals](docs/PROJECT_GOALS.md) suggest more directions. Pick something that interests you, or bring your own idea.

## Make it your own, and share what helps

Fork the repository, create a branch and explore. Your experiment can start small or take a different direction. If something would help other 54GUC users, open an issue or send a pull request. Draft pull requests are welcome.

A short explanation of what you changed and how you tried it helps others join in; include open questions too. The [offline test guide](docs/TESTING.md) and [Windows build guide](docs/BUILDING.md) will help you get started.
