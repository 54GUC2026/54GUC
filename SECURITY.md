# Security reports

Use the existing private project contact below. This document does not promise a response deadline or a supported-version policy.

Report suspected credential disclosure, unsafe control admission, cross-device data mixing or another security issue privately to `54guc2026@protonmail.com`, the contact in the existing release notice.

Include the application version, selected model/firmware, a concise impact description and a minimal sanitized reproducer. Do not send a router password, token, SIM/device identifier or full History unless a safe sharing method is explicitly agreed.

Do not publish an exploit-bearing support ZIP or private configuration in a public issue. Network-connected or router-changing reproduction must be explicitly authorized by the device owner. Existing third-party component security and licence obligations remain separate.
