# Security reports

Thank you for helping keep 54GUC and its users safe. For a suspected security issue, email **54guc2026@protonmail.com** so we can discuss it privately.

A short description, the app version and a small edited example are a useful start. If reproducing the issue needs sensitive information, we can discuss a suitable way to share it first.

For ordinary bugs, ideas and router reports, [open an issue](https://github.com/54GUC2026/54GUC/issues/new/choose).

<sub>See [project notes](docs/PROJECT_NOTES.md) for practical sharing tips.</sub>
